# vt (verify test)

検証・テスト用の一時作業領域です。

## ここに置くもの

- 隔離検証用のフィクスチャ
- 隔離ホーム(`HOME`/`USERPROFILE` を差し替える系の検証)
- ブラウザープロファイル
- ログ
- ユニットテストが作る一時ディレクトリー

## 注意

- 中身は `.gitignore` で除外されており、いつ消えてもよいものです。逆に **残しておきたいものをここに置かないでください**。
- 用途ごとにサブディレクトリーを切ってください。並行実行するエージェント同士が衝突しないよう、サブディレクトリー名は毎回変えてください。
- ドライブ直下(`C:\vt5` 等)に一時領域を作る従来のやり方は使わないでください。プロジェクト外に作ると後片付けがツールの保護に弾かれます。
